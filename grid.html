Clique num espaço vazio para adicionar um bloco. Arraste um bloco para movê-lo. Clique com o botão direito ou pressione Delete para apagá-lo. As setas do teclado movem o bloco selecionado.

Cantos livres arredondam para fora. Cantos que encontram um vizinho, mesmo na diagonal, arredondam para dentro. Um bloco contornado em branco está deslocado ¼ de célula dentro de uma forma conectada, o que a regra não permite.
